# Проект: AI-приложение для роста контент-креатора

Этот репозиторий — реализация системы, спроектированной в `/docs`.

## Порядок чтения для новой сессии Claude Code

1. `CLAUDE.md` — операционные правила, технологический стек, обязательные архитектурные границы
2. `CURRENT_STATUS.md` — текущее состояние проекта
3. `TASKS.md` — очередь задач
4. `DECISIONS.md` — история принятых решений (включая независимый архитектурный review)
5. `/docs` — полная архитектурная документация (45 файлов), source of truth по продуктовой и технической логике

При работе с окружениями, `.env` или деплоем — дополнительно `ENVIRONMENTS.md`.
При сомнении в точности цитаты из `/docs` или при обнаружении пробела в документированной схеме — сначала `DOCUMENT_CROSS_REFERENCE.md` (реестр уже найденных расхождений), чтобы не переоткрывать то же самое.

## Статус на момент создания репозитория

Phase 0 (документальный baseline) завершён и прошёл независимый архитектурный review. Следующая задача — Task 0.1 в `TASKS.md`.
